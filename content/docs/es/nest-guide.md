# Hosting en Nest

**Resumen:** [Nest](https://hackclub.app/) es el VPS (servidor privado virtual) de Linux gratuito de Hack Club. Obtienes tu propia máquina para desplegar sitios web, APIs, bots, bases de datos o cualquier otra cosa que se ejecute en un servidor. Para empezar, solicita una cuenta en [hackclub.app](https://hackclub.app/). Esta guía completa paso a paso todavía se está escribiendo, así que por ahora apóyate en la documentación oficial de Nest y en la gente amable del canal **#nest** en Slack.

## Lo que vas a aprender

- Qué es Nest y qué puedes ejecutar en él
- Dónde solicitar tu servidor gratuito y empezar hoy mismo

## Lo que necesitas

- Una cuenta del Slack de Hack Club, para poder solicitar acceso y pedir ayuda
- Un proyecto que quieras hospedar (un sitio web, una API, un bot, una base de datos o cualquier otra cosa que se ejecute en un servidor)

## Qué es Nest

[Nest](https://hackclub.app/) es el VPS (servidor privado virtual) de Linux gratuito de Hack Club. Obtienes tu propia máquina para desplegar sitios web, APIs, bots, bases de datos o cualquier otra cosa que se ejecute en un servidor. Es un gran lugar para poner tu proyecto en línea una vez que esté listo para compartir.
